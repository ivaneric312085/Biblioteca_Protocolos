BIBLIOTECA DIGITAL CUT — PROYECTO ANDROID
========================================
Este ZIP es un proyecto Android Studio, NO un APK compilado.
Requiere Android Studio, Android SDK 35 y conexión para descargar Gradle/dependencias.

CÓMO GENERAR EL APK:
1. Descomprime el ZIP.
2. En Android Studio selecciona Open y abre la carpeta Biblioteca_CUT_Android_Studio.
3. Espera a que Gradle sincronice. Si pide instalar Android SDK 35, acepta.
4. Menú Build > Build Bundle(s) / APK(s) > Build APK(s).
5. El APK de prueba quedará en app/build/outputs/apk/debug/app-debug.apk.
6. Copia el APK a tu teléfono Android e instálalo (autoriza la instalación desde esa fuente si procede).

CARACTERÍSTICAS:
- Pantalla de bienvenida animada con logotipo CUT.
- Catálogo de 11 PDF y portadas guardados dentro de la aplicación.
- Al tocar una portada, abre el PDF en un lector instalado en Android.
- Cinco portadas de video; abre YouTube/navegador con internet.
- Siete enlaces institucionales.
- Buscador, categorías, favoritos y modo oscuro.
- No necesita conexión para consultar los PDF.
- Compatibilidad: Android 7.0 o superior (API 24+).
- El APK NO está firmado para distribución pública; el debug APK es solo para pruebas.
